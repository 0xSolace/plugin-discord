Discord Activity Testing Guide

⚠️ Important: You cannot test Discord Activities by accessing http://localhost:5173 directly in your browser. Activities must be launched from within Discord.

Quick Start

Step 1: Ensure Discord Credentials are Set

Check that your ElizaOS .env file contains:

DISCORD_CLIENT_ID=your_discord_app_id
DISCORD_CLIENT_SECRET=your_discord_app_secret

The server will check these locations (in order):

  • plugin-discord/discord-activity/.env
  • plugin-discord/.env
  • eliza/.env (recommended)
  • ~/.eliza/.env
  • Current working directory

Step 2: Start the Activity Servers

Run the start script:

cd plugin-discord/discord-activity
./start.sh

This will start:

  • Client on port 5173
  • Server on port 3001
  • ngrok tunnel (if available)

Step 3: Create a Public URL

Discord Activities require a public HTTPS URL. Use one of these tools:

Option A: ngrok (included in start.sh)

ngrok http 5173

Option B: Cloudflared

cloudflared tunnel --url http://localhost:5173

Copy the generated URL (e.g., https://example.ngrok.io)

Step 4: Configure Discord Application

  1. Go to Discord Developer Portal
  2. Select your application
  3. Navigate to Activities → URL Mappings
  4. Add mapping: / → your public URL
  5. Save changes

Step 5: Launch the Activity

  1. Open Discord
  2. Join a server where your bot is present
  3. Join a voice channel or open a text channel
  4. Click the Activities button (🚀 rocket icon)
  5. Find "ElizaOS AI Assistant"
  6. Click Launch

Common Issues

Error: "frame_id query param is not defined"

This means you're trying to access the activity directly in a browser. Activities must be launched from Discord.

Error: "Discord Client ID not configured"

Your .env file is missing Discord credentials. Check the server logs to see which locations were checked.

Activity doesn't appear in Discord

  • Ensure Activities are enabled in Discord Developer Portal
  • Check that your bot has joined the server
  • Verify URL mappings are correct
  • Try refreshing Discord (Ctrl+R)

Development Tips

  • Use the browser console to debug when launched from Discord
  • Check server logs for configuration and connection issues
  • The status page at http://localhost:5173 shows server health
  • Hot reload works when developing - just refresh the activity in Discord
